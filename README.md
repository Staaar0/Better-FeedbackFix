# SilencedTracerBlocker

MetaMod:Source plugin for CS2 that blocks visible FireBullets tracers only for suppressed weapons, made for Better FeedBack-style tracer replacements.

## Behavior

- M4A1-S / USP-S with suppressor attached: tracer hidden, shot sound kept
- M4A1-S / USP-S with suppressor removed: tracer allowed
- MP5-SD: tracer hidden
- Other weapons: untouched
- Blood, wall impacts, decals, ricochet, taser: untouched

## Install

Copy the packaged `addons` folder into `game/csgo`.
