# SilencedTracerBlocker

MetaMod:Source plugin for CS2 servers using Better Feedback.

Blocks visible tracer feedback for suppressed M4A1-S / USP-S and MP5-SD while keeping shot sound, wall impacts, blood impacts, decals, ricochet and normal weapon tracers untouched.

## Install

Copy the packaged `addons` folder into `game/csgo`.
