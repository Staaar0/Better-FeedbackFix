## Better-FeedbackFix

# this plugin Made for the [Better FeedBack](https://steamcommunity.com/sharedfiles/filedetails/?id=3738685756) workshop addon.
# Better FeedBack have bug that allow silencer weapons to have visible bullets tracer to other players 
# this plugin hides custom bullets tracer for suppressed M4A1-S / USP-S shots while keeping normal effects untouched.

## Behavior

- M4A1-S / USP-S with suppressor attached: tracer hidden,
- M4A1-S / USP-S with suppressor removed: tracer allowed,
- MP5-SD: tracer hidden,
- Non-silenced weapons: untouched

## Install

Copy the packaged `addons` folder into `game/csgo`.
