## Better-FeedbackFix

# this plugin Made for [Better FeedBack](https://steamcommunity.com/sharedfiles/filedetails/?id=3738685756) workshop addon.
# Better FeedBack have bug that allow silencer weapons to have visible bullets tracer to other players ( Only On Windows Servers )
# this plugin hides custom bullets tracer for suppressed M4A1-S / USP-S shots while keeping normal effects untouched.

## Install

Copy the packaged `addons` folder into `game/csgo`.
